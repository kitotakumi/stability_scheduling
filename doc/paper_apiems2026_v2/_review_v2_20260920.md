### R2 §3.3（−9 行）
PR の Memetic 側括弧・(a)(b) の二段構え・$S_{cur}$・「修復」の語釈・搭載段落の深さスケジュール（表 1 と重複）・§4.2 への前方ポインタを削除:
> **Path Relinking（PR）.** PR は 2 つの高品質解を結ぶ経路上に優れた中間解が存在するという考えに基づく探索法で、一般にはエリート解プール内の解どうしを結ぶ形で用いられる [5][6]。本研究は **guiding solution を外乱前スケジュール $S_p$ の一点に固定する**。すなわち現在の局所最適解（initiating）から $S_p$（guiding）へ向け、両者が食い違う機械上の位置に $S_p$ の作業が来るよう入れ替える swap 移動で不一致を 1 つずつ縮めながら経路を辿り、経路上の最良解を返す。$S_p$ に固定するのは、$S_p$ が安定性目的の最適端点であり、$F(\lambda)$ 局所最適解から $S_p$ へ至る経路の中間解が MS–安定性トレードオフ上に並んでフロントを埋めるからである。各ステップの swap は実行可能な不一致から 1 つランダムに選び、評価回数を $O(d)$（$d$＝不一致数）に抑える。全候補を評価する best 選択は品質の利得が僅か（全域 HV で約 +1%）な一方、外乱が大きいと経路が伸びて計算時間が約 8 倍になるため採らない（予備実験）。
>
> **Stability Repair Kick（以下 repair）.** PR を途中で打ち切った演算子である。同じ swap 移動を深さ $k$（$1\le k\le d$）回だけ適用して解を $S_p$ 方向へ引き寄せ、経路上の中間解は評価せずに到達点を局所探索で再最適化する。$k=d$ なら $S_p$ まで戻り、小さければ現在解の近くに留まるため、$k$ を変えて繰り返すことで現在解と $S_p$ の間を幅広く埋める。
>
> **両構造への搭載.** 両構造には $S_p$ 方向への swap 移動という**演算子の核を共有させ**、発動の契機と返し方だけを各構造の標準的な組み込み方に合わせる（表 1）。単点探索（ILS）では両演算子は停滞時に発動する摂動として働く。多点探索（Memetic）では局所探索の後に個体ごとに確率的に適用し、結果を N5 で再最適化して無条件に集団へ戻す——採否はトーナメント選択に委ねる。以下、演算子を載せない構成を **ILS-baseline**・**Memetic-baseline** と呼ぶ。

（「この組み込み方の違いが結果を生んでいないことは §4.2 で確かめる」は §4.2 で閉じているので削除。残したければ −1 行。）
