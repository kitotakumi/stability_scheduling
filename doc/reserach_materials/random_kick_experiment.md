# ランダムキック対照実験（内的妥当性）— 正直な記録

> **本実験は国際学会版の論文には載せない**（理由は末尾）。本ディレクトリは生データと正直な解析記録を保全するためのもの。修論版での考察収録を検討する。

## 1. 目的

Memetic+PR / Memetic+repair の **高安定 HV 利得**が、

- (a) $S_p$（外乱前スケジュール＝最安定の極）**方向への誘導**によるものか、
- (b) 収束した集団を揺さぶる**一般的な多様化**によるものか、

を切り分けるための対照実験。**同強度・ランダム方向のキック**（repair と同じ深さ分布の direct swap を、方向だけランダム化したもの）を `memetic_random` として追加し、`memetic_ls`（無キック）→ `memetic_random`（多様化のみ）→ `memetic_repair`/`memetic_pr`（S_p 誘導）の3段で利得を分解する。

## 2. 結論（要約）

**当初の強い主張「高安定利得は $S_p$ 方向の誘導に固有・ランダムでは高安定フロントに届かない」は、正しい正規化で測り直すと支持されない。**

1. **高安定 HV 利得の大半は「多様化」**（無キック `ls` → `random` の大ジャンプ）。
2. **$S_p$ 誘導の上乗せ（`random` → 機構）は小さい**——la21 でほぼゼロ、la36L で小（+0.003, ただし δ=1.0 で一貫）。
3. 明確に残る差は **計算コスト約 7 倍**（random は $S_p$ から遠くへ飛ぶため、キック後の局所探索の再収束が高コスト。repair/PR は $S_p$ を狙うので安い）。
4. ⇒ 機構の価値は「品質に必須」ではなく「**同等の高安定品質を、構造化ターゲットにより効率的に達成する**」点にある。

## 4. ⚠️ 解析上の2つの落とし穴

`diagnostics/random_kick_control.py` をそのまま使うと**誤った結論**になる。実際、素朴な解析では「repair ≫ pr・random は高安定に届かない」と出るが、これは下記2点のアーティファクトである。

1. **正規化(make_norm)と P50 を、その問題 dir 内の4手法だけから再計算する。** main_v1 は全7手法×10重みから正規化を作るのに対し、対照 dir には GA/ILS が無く効率重みも間引かれているため、正規化アンカーが非整合になる（HV 値も手法間の大小も歪む）。
2. **random のコスト都合で4重みに間引いたことが memetic_pr の高安定被覆を過小評価する。** 例: mt10 の pr 高安定は **4重みだと 0.021 だが、全10重み（main_v1）では 0.044 ＝ repair と同じ**。repair は4重みでも0.044で安定。pr が高安定を埋める重みが間引きで漏れている。

→ **正しい比較は「main_v1 の norm + P50 に random を置いて、同一4重みで測る」。** 以下は補正版。

## 5. 補正版の結果（main_v1 の norm + P50, 4重み）

### 5.1 高安定 HV（D<P50）の分解

| 問題(リスケ率) | ls(無キック) | random(多様化) | repair | pr | **多様化** (ls→rand) | **S_p誘導** (rand→機構) |
|---|---|---|---|---|---|---|
| la36L (73%) | 0.0148 | 0.0296 | 0.0328 | 0.0327 | **+0.0148** (p=.001, δ=+1.0) | repair +0.0032 / pr +0.0031 (p=.001, δ=+1.0) |
| mt10 (72%) | 0.0121 | 0.0286 | 0.0437 | 0.0210 † | **+0.0165** (p=.005, δ=+.64) | repair +0.0151 (p=.014, δ=+.82) / **pr は random に負け (ns)** † |
| la21 (35%) | 0.0290 | 0.0607 | 0.0613 | 0.0613 | **+0.0317** (p=.001, δ=+1.0) | repair/pr +0.0006 (p=.008/.016, δ≈+.65) |

† mt10 の pr は §4 の4重み間引きで過小評価（全10重みの main_v1 では pr = repair = 0.044）。よって mt10 の「pr が random に負ける」は protocol アーティファクトであり、アルゴリズムの差ではない。

**読み**: どの問題でも `ls → random` の多様化ジャンプ（+0.015〜0.032）が `random → 機構` の誘導上乗せ（+0.0006〜0.003、mt10-repair のみ +0.015）より大きい。高安定利得の主因は多様化。

### 5.2 統合 HV（参考, 同 norm / 4重み, 中央値）

| 問題 | ls | random | repair | pr |
|---|---|---|---|---|
| la36L | 0.876 | 0.925 | 0.919 | 0.912 |
| mt10  | 0.607 | 0.627 | 0.638 | 0.616 |
| la21  | 0.970 | 1.012 | 0.946 | 1.022 |

→ 統合 HV は random ≈ repair ≈ PR（三者とも ls には勝つ）。**統合 HV 上の「+機構 > 無機構」利得はほぼ多様化効果**で、S_p 方向は統合 HV にはほぼ寄与しない。

### 5.3 計算コスト（total_cpu_time, 秒/run）

| 問題 | ls | repair | pr | random | **random / repair** |
|---|---|---|---|---|---|
| la36L | 74.8 | 301.9 | 509.4 | 2196.4 | **7.3×** |
| mt10  | 21.1 |  78.4 | 128.2 |  200.8 | **2.6×** |
| la21  | 17.6 |  71.1 | 119.0 |  134.0 | **1.9×** |

→ random は同強度でも repair の **1.9〜7.3 倍**のコスト（規模・リスケ率が大きいほど顕著）。構造化ターゲット $S_p$ への移動はキック後 LS が安い。

## 6. 妥当性チェック: run 自体は正しい

mt10 の `memetic_pr` / `memetic_repair` の最終解 (MS, D) は **main_v1 と完全一致**（同一シード・決定的）。run に問題はなく、§4 の見かけの差は解析正規化と重み間引きに起因する。

## 8. なぜ学会版に載せないか

- 元の役割は「機構の高安定利得は $S_p$ 方向に固有（多様化では届かない）」の論拠だったが、**実データはこれを否定**した（多様化主因・差はコスト）。
- 残る効率（7×）の話は副次的かつ半ば構成上自明（$S_p$ を狙えばキックが小さく LS が安い）。
- tight な国際学会論文では、この対照を載せると「検証対象だった強い主張」を自分で弱めることになり割に合わない。**「$S_p$ 方向が品質に必須」という主張自体を撤回すれば、対照実験は不要**になる（H2 の非対称＝機構 vs 無機構の比較は random 対照なしで robust に立つ）。
- 隠蔽ではない：検証対象の主張をしなくなるため、対照を省くことは整合的。**修論版**では本記録に基づき「多様化主因＋効率＋小さな一貫上乗せ」を考察として収録を検討する。
