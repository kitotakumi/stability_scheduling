# 計算予算（ILS 3000反復 / GA・Memetic 500世代）の妥当性検証

2026-06-13 実施。core_comparison_v3 本実験の開始前に、現行予算が「短すぎないか・長すぎないか」を既存データで検証した記録。

- **データ**: param_sweep_v1 本番再掃引の center 設定 run（現行コード・現行予算そのもの）
  - la21_delay147: `results/sweep_20260610_141059`（center 420 run = 7手法 × 6重み × n=10）
  - la36_large: `results/sweep_la36`（center 300 run = 5手法 × 6重み × n=10。memetic_ls / memetic_repair の掃引軸なし）
- **予算**: ILS max_iter=3000 / GA・Memetic ngen=500（本実験と同一）
- **スクリプト**: `tools/check_budget_adequacy.py`（時刻ベース指標）、`tools/check_budget_tail_gain.py`（品質ベース指標）

## 指標の定義（いずれも run 内の総 CPU 時間 T に対する比率）

| 指標 | 意味 |
|---|---|
| scalar最終改善 | 重みスカラー best_score が最後に改善した時刻 / T |
| PF最終更新 | per-trial Pareto front（UEA・baseline除外後）が最後に更新された時刻 / T |
| HV99% / 99.9% 到達 | 自身の最終 HV の 99% / 99.9% に到達した時刻 / T（self-referenced, per-run 参照点） |
| 残り20%(50%)で得たHV | (HV(T) − HV(0.8T)) / HV(T)。**予算を+20%増やして買える量の上限**（HV(t)は凹型に飽和するため） |

## 解釈

1. **長すぎない**: 中央値の run は予算の半分前後で最終 HV の 99% に到達 ＝ 典型 run に対し約2倍の安全率（教科書的に推奨されるマージン）。一方で p90 の run は予算の 8〜9 割まで使うため、半減（1500反復/250世代）は上位1〜2割の run のフロント充填を切り落とす。コード内の旧コメント「last_improvement p_max×1.5 → 1500 で十分」は**キック再設計前**の分析であり、キック時代は収束後も安定性側フロントを掃き続けるため当てはまらない。
2. **短すぎもしない（中央値ベースでは）**: 終盤 20% の時間で買えた HV は中央値で全手法ほぼ 0%。主指標（per-trial union UEA HV の中央値 + Wilcoxon）は予算を増やしてもほぼ動かない。
3. **大外乱問題の裾**: la36 では手法を問わず（ILS+PR 含む）下位 ~10% の run が終盤 20% で最終 HV の 1〜4%（最大 ~12%）をまだ稼いでいる。これは「GA系の予算不足」ではなく**大外乱問題は収束の裾が重い**という問題側の性質。打ち切りの向きは la36 最強の Memetic+PR が最も損をする方向＝提案手法に不利な保守的方向であり、主張の妥当性は守られる。
4. **注意（運用制約）**: ngen / max_iter の増額は resume と非互換（既存 raw は完成品として保存され延長不可）。予算は**回す前に確定**する必要がある。

## 補遺: 四分位で見た終盤ゲイン（報告統計＝中央値[IQR]への影響確認）

論文の報告形式（union HV 中央値 [Q25, Q75]・Wilcoxon・Cliff's δ）が予算に感応するかを、
gain_last20 の分位で確認（`tools/check_budget_tail_quartiles.py`）。
trial単位 = そのtrialの全重みrunのgain平均（per-trial union HV への影響の保守的な上界。
union は最良フロントに支配されるため実際の影響はこれより小さい）。

| 問題 | 手法 | run単位 Q25/med/Q75/p90 | trial単位 Q25/med/Q75/max |
|---|---|:---:|:---:|
| la21 | GA | 0 / 0 / 0.8 / 3.9 % | 0.4 / 0.9 / 1.8 / 4.1 % |
| la21 | ILS系3種 | 0 / 0 / 0 / ~1.1 % | ~0.1 / ~0.2 / ~0.4 / ~1.0 % |
| la21 | memetic系3種 | 0 / 0 / ~0 / ≤0.5 % | ~0.02 / ~0.1 / ~0.2 / ≤1.3 % |
| la36 | GA | 0 / 0 / 0.1 / 2.9 % | 0 / 0.2 / 2.5 / 3.6 % |
| la36 | ILS+PR | 0 / 0 / 0.1 / 4.2 % | 0.02 / 0.2 / 1.3 / 4.6 % |
| la36 | ILS+repair | 0 / 0 / 0 / 1.0 % | 0.1 / 0.4 / 1.0 / 1.6 % |
| la36 | ILS-baseline | 0 / 0 / 0 / 0.0 % | 0 / 0 / 0.01 / 3.3 % |
| la36 | Memetic+PR | 0 / 0.06 / 0.7 / 3.8 % | 0.2 / 0.8 / 1.6 / **2.7** % |

**読み**: run単位では Q75 ですら全セル <1%。遅咲きの裾は p75 より上にしか存在しない。
trial単位（union HV への影響上界）でも最悪セル（la36 Memetic+PR）で max 2.7%・Q75 1.6%。
手法間の差は +13〜54% なので、**中央値だけでなく Q25/Q75（IQRの両端）も予算増では実質
動かず、順位の入れ替わり・検定の符号反転は起こり得ない**。
唯一の例外は改善成功率のような二値指標（la36のILS 0.5〜0.6）: 裾のrunが1本flipするだけで
5/10→6/10 と動くため、予算の影響がゼロとは言えない（ただし全手法同条件で伸ばす限り公平）。

## 選択肢と判断

| 案 | 内容 | コスト | 効果 |
|---|---|---|---|
| A | 500/3000 のまま + 事後の検証セル（la36_large × {memetic_pr, ga} × 代表重み1点 × n=10 × ngen=1000） | 検証セル ~3-4時間 | 中央値統計は同等。脚注で予算批判を防御 |
| B | GA系 700世代 / ILS 4000反復 に増額 | 実験全体 +30〜40%（壁時計 +6〜8時間/全問題, 8並列） | 下位10% run の裾をほぼ確実に飽和。フォローアップ不要のワンショット保険 |
| C | 半減（250/1500） | −50% | **不可**。p90 run のフロント充填を切り落とす |

検定の中央値ベース統計だけ見れば A で十分。一発勝負で後から延長できない点を重く見るなら B も合理的（族内等予算は保たれ、方法論上の問題はない。掃引が 500/3000 で行われた点は「掃引は感度確認・本実験は十分予算」と説明可能）。

**決定（2026-06-13）: 案A採用 — GA・Memetic 500世代 / ILS 3000反復のまま本実験を実施。**
根拠: 報告統計は全て分位・順位ベース（中央値[IQR]・Wilcoxon・Cliff's δ）であり、補遺の四分位分析の通り run単位 Q75 でも終盤ゲイン <1%、trial単位の union HV 影響上界も最悪 2.7% ＝ 手法間差（+13〜54%）の1/10以下。順位・検定の反転余地なし。
留保: 改善成功率（二値指標, la36 の ILS 0.5〜0.6）のみ裾 run の flip で動き得るが、limitation の記述強度が変わる程度で主張に影響しない。本実験の anytime 曲線で未収束の兆候が見えた場合のみ、検証セル（la36_large × memetic_pr × 代表重み × ngen=1000, n=10）を事後追加する。

## 事後確認: 本実験 main_v1 そのものでの再検証（2026-06-19）

事前検証は本実験 *前* の param_sweep データだったため、実際の本実験
`results/main_v1`（7手法 × 10重み × **6問題** × n=10 ＝ 全 4,200 run）で収束を再確認した。
スクリプト: `experiments/core_comparison_v3/diagnostics/check_budget_main_v1.py`。

### 収束（残り20%予算で買えるHVの上限 = gain20）

**中央値 run は全6問題×全7手法で gain20 = 0.00%** ＝ 典型 run は完全飽和。差が出るのは
遅咲きの裾(p90)のみ（単位 %）:

| 問題 | GA | ILS-base | ILS+rep | ILS+PR | Mem-LS | Mem+rep | **Mem+PR** |
|---|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| mt10 | **14.2** | 3.1 | 3.8 | 1.7 | 0.56 | 0.07 | **0.06** |
| la21 | 4.9 | 1.1 | 0.7 | 0.6 | 0.14 | 0.23 | **0.06** |
| la40 | 4.2 | 1.8 | 0.3 | 0.0 | 0.0 | 0.0 | **0.0** |
| la36_large | 2.1 | 0.06 | 0.4 | 4.2 | 3.7 | 0.67 | **0.32** |
| la36_small | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| ta21 | 1.7 | 0.2 | 0.7 | 0.2 | 0.25 | 0.06 | **0.06** |

- 最も収束が浅い（予算を使い切る）のは提案手法ではなく **GA ベースライン**。提案の Mem+PR は
  全問題で p90 ≤ 0.67% ＝ **全手法中もっとも飽和**。
- ILS の PF 最終更新反復（予算3000）: 中央値 453〜1646（半分以下で収束）、p90 2400〜2800、
  max ~2970〜2999（裾の数本のみ末端まで更新）＝ 事前検証と同じ「大外乱=裾が重い」パターンで
  予算不足ではなく問題側の性質。la36_small は全手法ほぼ瞬時収束（ILS med iter=1, 実時間6秒）。
- 打ち切りの向きは GA・大外乱問題側が最も損 ＝ **提案手法に不利な保守的方向**。

### 族間の予算感（総CPU時間 T 中央値, 秒）

| 問題 | GA | ILS(3種) | Mem-LS | Mem+rep | **Mem+PR** |
|---|:--:|:--:|:--:|:--:|:--:|
| mt10 | 31 | 24–25 | 20 | 72 | **122** |
| la21 | 47 | 16 | 17 | 75 | **125** |
| la40 | 68 | 26 | 28 | 134 | **221** |
| la36_large | 75 | 85–90 | 76 | 276 | **481** |
| la36_small | 64 | 6 | 12 | 60 | 61 |
| ta21 | 121 | 60 | 58 | 259 | **389** |

- **ILS 3種は互いにほぼ等時間** ＝ ILS 内部比較は壁時計でもフェア。
- 名目予算（500世代 vs 3000反復）は族の軸ごとに揃うが**壁時計は揃わない**:
  Mem+repair ≈ ILS の 4〜5倍、**Mem+PR ≈ 5〜8倍**。主因は飛散した集団から $S_p$ への長い経路 decode（O(n·diffs)＝経路長比例）＋ top-k LS×3 であり、O(diffs²) の候補フルコピーは実測 ~10% で主因ではない（[[pr_decode_cost_and_aoc_consistency]] §2 の B1 実験で確定）。
- ただし**この超過コストは勝因ではない**: Mem+PR は既に頭打ち（gain20 p90 ≤ 0.67%）＝
  余分な CPU を使い切っていない。逆に ILS の裾もほぼ平坦なので、ILS に Mem+PR 並みの壁時計
  （≈5倍反復）を与えても +13〜54% の HV 差は埋まらない。**勝因は構造であって予算ではない。**

### 結論（2026-06-19）

**現行予算（GA・Memetic 500世代 / ILS 3000反復）のままで問題なし。変更不要。**
事前検証(2026-06-13, 案A)の前提が本番データで裏付けられ、未収束の兆候は皆無のため、
留保していた検証セル（la36_large × memetic_pr × ngen=1000）も**不要**と判断。
唯一残る論点は「名目予算は等しいが壁時計は等しくない」だが、これは機構固有コストであり
予算問題ではない。査読対策としては名目予算と壁時計 T を両方透明に報告し
「ILS は既にプラトー＝追加時間でも差は埋まらない」と注記すれば守れる。
