# ゼミ発表資料（2026-04-19 週）

## 今週の要点

- 先行的な軽量実験で、**ILS および ILS+repair 摂動** が GA に対して「解の質」と「計算速度」の両面で優位性を持つ見込みを確認した。
- その結果を踏まえ、**本格的な比較実験を走らせるための実験設計**を策定した。本資料はその設計内容の説明。

---

## 1. 研究の対象と前提

- 問題: JSSP の**再スケジューリング**（遅延などの外乱で崩れた初期解を作り直す）。
- 目的: **メイクスパン（効率性）** と **安定性（初期解からのジョブ投入順序の変更量）** の 2 目的を、重み付き合成スコアで最適化する。
- 安定性は `Σ_m Σ_j |rank_init − rank_current| / (rank_current + 1)^1.25` で定義（先頭ジョブの変更を重くペナルティ）。

---

## 2. 手法の説明

比較対象は 4 種（メメティックは任意、優先度低）。

| 手法 | 種別 | 位置付け |
|---|---|---|
| GA | 集団ベース進化計算 | 主比較対象 |
| メメティック（任意） | GA + 局所探索 | 査読対応用、優先度最低 |
| ILS-baseline | 単一軌跡の反復局所探索 | ベースライン |
| ILS + repair 摂動（+ PR 関連） | 提案手法 | 本研究の主役 |

### 2.1 ILS（Iterated Local Search）のざっくり説明

単一の現在解から **「局所探索（深掘り）」→「摂動（脱出キック）」→「受理判定」** を繰り返す探索法。

```
current = 初期解
while 予算が残っている:
    perturbed = 摂動(current)          # 局所最適から強制的に飛ばす
    local_opt = 局所探索(perturbed)    # 近傍で改善できる限り改善
    if 受理条件(local_opt):
        current = local_opt
```

- **局所探索**: N5 近傍（クリティカルパス上のブロックの端点 swap）で山登り。Nowicki & Smutnicki (1996) により **閉路フリー** が理論保証されている。
- **摂動**: `swap`（N5 swap を連続適用）または `insert`（1 op を抜いて別位置へ挿入）。強度は停滞カウンタで段階的に増加。
- **本研究の ILS の特徴**:
  - 解表現は **machine_orders（機械ごとのジョブ列）** を直接操作。
  - `best`（全体最良）と `current`（次の摂動出発点）を分離管理。
  - Taillard 加速（合成スコア下界フィルタ）で重い `build_gantt` をスキップ。

**GA に対する構造的優位の仮説**: GA の交叉は良質な初期解の構造を破壊するが、ILS は「深掘り」と「脱出」が分離されているため、**安定性を制御しながら効率的に探索できる**。

### 2.2 repair 摂動（Mini-PR kick, P-1）のざっくり説明

通常の摂動は「ランダムに壊す」方向だが、repair 摂動は **「初期解に近づく方向」** へのキック。

```
初期解と現在解の machine_orders を比較 → 不一致位置を列挙
     ↓
不一致位置から K 個選び、direct swap で初期解の順序に合わせる
     ↓
出発点を安定性方向に偏らせて局所探索にかける
```

- **direct swap**: 目標位置にあるべきジョブを、現在機械列の中から探して **一気に swap で持ってくる**（隣接 swap を何度も重ねず 1 ステップ）。
- **ねらい**: バイアスのかかった出発点から LS を走らせると、**別の盆地（basin）に落ちて結果的に安定性の良い局所最適へ到達する**。
- 通常の swap/insert 摂動を置き換えるのではなく、**停滞時のキックとして組み合わせて使う**設計。
- パラメータ: `repair_trigger`（停滞何回で起動するか）、`repair_strength`（何 op 直すか）。

### 2.3 Path Relinking（PR）について

2 つの良質解 `s`（始点）と `t`（目標解）を取り、**`s` から `t` の属性を少しずつ導入する経路**を辿り、その途中で良い中間解を拾う手法。

- 移動戦略: JSP では「目標解で位置 i にいるべきジョブを direct swap で寄せる」形が自然。
- 本研究での扱い: **direct swap のムーブ戦略は repair 摂動として流用**し、実験の中核で使っている。
- **PR 単体としての再評価の余地**: 先行実験（2026-04-08）では「重み付きスカラー値のみ」で評価し、「経路上にスカラー改善がない」として不採用とした。しかし、本研究の評価軸を **Pareto front / HV / 差分 EAF** に切り替えると判断が変わる可能性がある:
  - PR の中間解は特定重みでのスカラーは悪くても、**MS–Stab 平面では非劣**（Pareto 貢献あり）のことがある。
  - スカラー優位性 ≠ Pareto 貢献度なので、先行判断はそのまま適用できない。
  - コア実験（実験 1）で得る union Pareto / HV の枠組みで PR を改めて評価できる設計になっている。必要なら 実験 4〜5 と並列で **PR の再評価枠**を立てる。

## 3. 研究の主張（4 つ）

本研究が本格実験で検証したい主張。

| ID | 主張 | 位置付け |
|---|---|---|
| **(A)** | **ILS は GA より構造的に高速** — 同 CPU 時間でより良い解に到達する | **最重要** |
| (B) | **ILS（+repair）の Pareto 覆域は GA を凌駕する** — CPU 時間予算に依らず、多目的探索力そのもので上回る | 品質の裏付け |
| (C) | **repair 摂動は baseline ILS の Pareto を安定性側へ系統的に拡張する** | 提案機構の貢献 |
| (D) | **ILS は重み設定に対して頑健、GA は高 stab 重みで degenerate** | 新規な発見 |

**(D) の背景**: GA は stab 重み ≥ 0.3〜0.5 で「初期解が Stab=0 の最良点」として集団全体が固着し、動けなくなる（交叉・突然変異が disruptive すぎて脱出できない）。ILS は単一軌跡の摂動でこの罠を避けられる。

**副次観察**:
- MS と安定性は構造的トレードオフ（PR 実験・repair 実験で確立）。
- ILS の単一軌跡内では「MS 維持のまま安定性だけ改善」は見つからない（post-hoc 修復が困難）。

- **履歴を保存**して、同じ実行データから以下を全部生成する:

  - 任意時刻の snapshot Pareto front

- **アルゴリズムは重み付きスカラーのまま**動かし、**評価段階で多 weights の結果を集約**して Pareto front を作る（PILS 化などアルゴリズム改造は不要）。

## 5. 従属変数 ①: 解の質（4 軸）

### 5.1 総合探索力

手法がどれだけ広く良い領域を覆えているかの集約指標。

#### HV（Hypervolume, 超体積）

- **何か**: 多目的最適化で得られた Pareto front の「良さ」をスカラー 1 値で測る指標。
- **計算**: Pareto front と**参照点（nadir）**で囲まれる領域の体積（面積）を測る。**大きいほど良い**。
- **本研究での使い方**:
  - per-trial Pareto を抽出 → 手法ごとに 10 trial を union → union Pareto の HV を比較。
  - weights は全水準の結果を混ぜて 1 本に集約する（多目的指標なので weights 横断で正しい）。
- **ポイント**: 参照点を揃える必要がある（問題・外乱ごとに nadir + マージンで固定）。

```
  stab
   │
   │  ●───┐          ← Pareto front（各点が 1 解）
   │      ●───┐
   │          ●───┐
   │              ●───●  ← 参照点
   └─────────────────→ MS

   HV = 塗りつぶし面積
```

#### C-metric（Coverage metric, 2 集合間 dominance 率）

- **何か**: 2 つの Pareto 集合 A, B について **「B の点のうち A にドミネートされている割合」** を測る。
- **計算**: `C(A, B) = |{b ∈ B : ∃a ∈ A, a ≻ b}| / |B|`。0〜1 の値。`C(A, B) > C(B, A)` なら A 優位。
- **HV との違い**: 参照点が不要。dominance 関係を直接測れる。
- **使い方**: 手法ペアごとに C 値の表を作る（Table 3）。

### 5.2 最終選択値（実用性）

運用上 1 解を選ぶ立場で見た質。

| 指標 | 意味 |
|---|---|
| scalar 値（代表 weights） | 実際の重み付きスコア |
| メイクスパン（MS） | 効率性の生値 |
| 安定性評価値（Stab） | 初期解との順位偏差の生値 |

weights ごとに別々に報告する（集約しない）。

### 5.3 探索構造（どこで勝っているか）

同じ HV でも「どの領域で優勢か」が違うと示唆が異なる。

| 指標 | 中身 | 用途 |
|---|---|---|
| **Conditional HV（領域別）** | 例「stab 下位 25%」限定の HV | **低 stab 領域での優勢**を定量化（主張 B） |
| **Attainment surface 曲線** | 50% quantile の「MS = X で到達できる最良 stab」曲線 | 方向別の到達深度を可視化 |
| **差分 EAF プロット** | 領域ごとに A/B どちらが勝っているかを色分け | **可視化専用**（conditional HV と数値等価） |

> 数学的に `∫∫_R (α_A − α_B) dp = E[HV_R(A)] − E[HV_R(B)]` なので、差分 EAF の**定量化は conditional HV に寄せる**方針。差分 EAF は「視覚的にどこで勝っているか」だけを示す。

### 5.4 頑健性

| 指標 | 中身 | 用途 |
|---|---|---|
| **改善成功率** | trial のうち「final MS = init MS」になった割合の逆 | GA の degeneracy（固着）を定量化（主張 D） |

→ 重み × 手法のヒートマップで可視化（Fig 7）。

### 5.5 集約レンジの 2 ケース併記

GA が高 stab 重みで degenerate するので、集約レンジで HV の意味が変わる。両方報告する。

| ケース | 集約対象 weights | 役割 |
|---|---|---|
| 案 A: 全 weights | 6 点すべて | メイン。degeneracy も含めた正直な差 |
| 案 B: fair range | GA も動く範囲（4 点）| 補足。「degeneracy を差し引いても ILS が勝つ」の証拠 |

→ 「ILS は degeneracy の恩恵で勝ってるだけでは？」の反論を **2 段構え**で封じる。

## 6. 従属変数 ②: 計算速度

主張 (A) の中核指標。履歴から anytime curve を描く。

| 指標 | プロット | 見る対象 |
|---|---|---|
| CPU 時間 × HV（full） | anytime curve | 総合品質到達の速度 |
| CPU 時間 × HV（conditional: 低 stab 領域） | anytime curve | 安定性方向探索の速度 |
| CPU 時間 × scalar 値（代表 weights） | anytime curve | deployment 視点の速度 |

### 評価の仕方

- 同一 CPU 時間の**断面**（T = 5, 10, 20, 40 秒）で各指標を比較 → snapshot 表にする。
- **ある固定 T でどちらが勝つか** + **その差が T とともにどう推移するか**の両方を議論する。
- weights の扱い:
  - **HV 系**: 全 weights × 全 trial を union して **1 本の曲線**。
  - **scalar 系**: 代表 weights（例 `[0.9, 0.1]`, `[0.8, 0.2]`）ごとに**独立の曲線**。

## 付録: 用語ミニ辞典

| 用語 | 意味 |
|---|---|
| machine_orders | 機械ごとのジョブ（操作）列。本研究の解表現 |
| N5 近傍 | クリティカルブロックの端点 swap のみ。閉路フリー保証 |
| semi-active schedule | 各操作を可能な限り早く開始。隙間への左詰めはしない |
| direct swap | 目標位置のジョブを 1 ステップの swap で寄せるムーブ |
| Pareto front | どの目的でも他にドミネートされていない非劣解の集合 |
| Hypervolume (HV) | Pareto と参照点で囲まれる体積（大きい＝良い） |
| C-metric | 2 集合間の dominance 率（参照点不要） |
| EAF | Empirical Attainment Function。trial 集合から「ここまで到達した確率」の場を構成 |
| Conditional HV | 特定領域限定の HV（方向別の優勢を定量化） |
| degeneracy | GA が高 stab 重みで初期解に固着し動けなくなる現象 |
