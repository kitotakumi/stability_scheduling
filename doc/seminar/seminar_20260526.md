## 1. 研究の 2 軸提案（再整理）

本研究の提案は以下の 2 本柱から構成される。

### 軸 I: ILS の有効性

再スケジューリングでは崩れる前の初期解 S₀ が手元にあり、新しい解は S₀ に「近い」ほど望ましい（安定性）。
この性質から、集団ベース (GA) より**単一解ベース**のほうが本問題と相性が良い。

> GA は交叉で S₀ の構造を壊しやすく、高安定性重みでは初期解から動けなくなる（degeneracy）。
> 単一解ベースは S₀ から連続的に変形するため、S₀ との距離を制御しやすい。

単一解ベースの中でも **ILS（Iterated Local Search）** を選ぶ理由:

- LS と摂動が分離されているため、**各役割が明確** で解析しやすい
- 摂動強度 K が「S₀ からの破壊量」を直接決めるレバーになる
- **PR や repair のような外部機構を摂動として差し込みやすい**（後述の軸 II に直結）

![GA と ILS の探索挙動](ga_vs_ils_rescheduling.svg)

| 観点 | GA | ILS |
|---|---|---|
| 状態 | 集団 (population) | 1 本の `current` 解 |
| 主操作 | 交叉 + 突然変異 | 摂動 + 局所探索 |
| 構造の保存 | 交叉で **2 親を切り貼り** → 破壊的 | 元解からの **連続変形** → 構造を保持 |
| 摂動強度の制御 | 交叉率は集団全体に効く（読みにくい） | 摂動強度 = **「S₀ からの距離」を直接決めるレバー** |
| 速度 | 世代を重ねるほど遅くなる | 1 反復が軽量 → **同 CPU 時間でより多くの探索** |

→ 速度（主張 A）と per-weight 解の質（主張 B-1）の構造的根拠。

### 軸 II: PR・repair による初期解方向への引き戻し

再スケジューリングでは S₀ 方向の安定性が要求される。通常の摂動（ランダムな swap/insert）は安定性方向の盆地に到達しにくい。

**Path Relinking (PR)** は始点 s と目標 t を結ぶ経路を辿る手法。

```
       s ●───────────────●───────────────● t
                  ↑               ↑
              中間解 m₁        中間解 m₂

   各 mᵢ は s の属性を t の属性へ少しずつ置き換えた解
```

JSP では解を `machine_orders`（機械ごとのジョブ列）と見たとき、**不一致位置を 1 つずつ t に合わせる** のが経路。
ムーブは **direct swap**（離れた位置のジョブを 1 ステップで交換）。

![direct swap の動作](direct_swap_focused.svg)

再スケジューリングでは **目標 t として初期解 S₀ が常に手元にある**。
→ PR の「t に寄せる」操作がそのまま「安定性方向への引き寄せ」になる。

**repair 摂動**はこの発想を ILS の摂動キックに転用した Mini-PR kick:

```
①  S₀ と現在解 S* の差分を確認
②  不一致位置から K 個を選んで direct swap で S₀ に合わせる
③  S₀ に少し寄った解を出発点として LS にかける
```

→ 「S₀ への引き寄せ」という方向性を持った脱出キックとなり、安定性側の Pareto 覆域を拡張する（主張 B-2）。

## 2. 研究方向の拡張: ILS+PR から GA との組み合わせへ

### 2.1 ILS+PR の効果が微小だった原因

これまで ILS-baseline に PR を追加することで Pareto 前線の安定性側が拡張されるという仮説を持っていた。pilot_v3 の結果では ILS+PR は ILS-baseline と同等程度であり、**相乗効果は限定的**だった。

**構造的原因**:

ILS は単一解ベースのため、探索中の解が S₀ の近傍に留まりがちである。PR は「始点 s → 目標 t (= S₀)」の経路を辿るが、始点 s が S₀ に近いと**経路が短くなり、途中の中間解に改善可能な盆地が少ない**。

```
ILS の場合（S₀ に近い解から PR）:
  s ●──●──● t(=S₀)    経路が短い → 中間解が少ない

GA の場合（S₀ から遠い解から PR）:
  s ●───────────────────●──● t(=S₀)    経路が長い → 中間解が多く改善の余地が大きい
```

GA は集団ベースの**広域探索**により S₀ から遠い位置にある解を見つけやすい。そこから S₀ に向かって PR で経路を引くと、**改善可能性のある中間解が多く発見できる**。

### 2.2 GA との組み合わせという方向へ

```
ILS:  current(S₀ 近傍) ──短い経路──▶ S₀    （効果が薄い）

GA :  個体①(S₀ から遠い) ──長い経路──▶ S₀   （中間解に改善余地）
      個体②(S₀ から遠い) ──長い経路──▶ S₀   （集団から複数経路）
      個体③               ──        ──▶ S₀
```

さらに GA+LS（Memetic）であれば LS による精緻化も加わり、各個体が局所最適付近に留まることで PR の始点の質も向上する。
今回は **GA + LS + PR/repair** という組み合わせ（Memetic）も研究対象に加えた。

これにより実験の手法は以下の 7 つに拡張された：

| 手法 | 説明 |
|---|---|
| GA | 重み付き GA（比較ベースライン） |
| ILS-baseline | 重み付き ILS（単一解ベースライン） |
| ILS+repair | baseline + repair 摂動キック |
| ILS+PR | baseline + Path Relinking |
| **memetic_ls** | GA + LS（各世代後に LS 適用） |
| **memetic_pr** | memetic_ls + PR |
| **memetic_repair** | memetic_ls + repair 摂動 |

## 3. 評価設計（pilot_v3）

評価の詳細は [evaluation_design.md](../evaluation_design.md) に定義している。ここでは骨子のみ整理する。

### 3.1 研究の 3 軸主張と対応指標

| 主張軸 | 内容 | 主指標 |
|---|---|---|
| **(A) 速度** | ILS は GA より構造的に高速（同 CPU 時間で優れた解） | per-weight anytime scalar curve |
| **(B-1) per-weight 質** | weight 別に ILS 系は GA より高品質。GA は高 stab 重みで degenerate | per-weight scalar 値 + 改善成功率 |
| **(B-2) 統合 Pareto 質** | weighted sum sweep の union 解集合で ILS 系・Memetic 系が上 | **HV** + **領域別 HV** |

### 3.2 Weighted sum sweep

多目的最適化の比較は **weighted sum scalarization sweep** で行う。

- weight = [eff, stab] を 0.1 刻み 11 点 (`[1.0,0]` ～ `[0.0,1.0]`) で振る
- 各 weight で 1 run、その全結果を union → non-dominated 抽出 → Pareto front

```
weighted sum sweep の Pareto front イメージ:

         MS (効率性) ↓
         ┌─────────────────────────────
     高  │  ●─●         ← w=[1.0, 0.0]（効率性偏重）
  安 ↑   │     ●─●
  定      │        ●─●
  性      │           ●─●─● ← w=[0.0, 1.0]（安定性偏重）
         └─────────────────────────────
          （各点が異なる weight の最終解）
```

### 3.3 HV と領域別 HV

- **HV (Hypervolume)**: Pareto 前線が参照点を覆う超体積。大きいほど多目的性能が高い。各 trial で weighted sweep 全解を統合した Pareto front に対して計算し、trial 間の中央値で比較する。
- **領域別 HV (Region HV)**: stab 軸を P33/P67 で 3 分割し、low/mid/high_stab 領域ごとに HV を算出
  - 高安定性領域の覆域を個別に評価することで「どの手法がどの安定性帯に強いか」を分解できる
  - 境界 P33/P67 は全手法・全 trial の解を一括プールして機械的に決定（1 実験 1 回固定）

## 5. 暫定的な解釈

### 5.1 ILS+PR の相乗効果が限定的な理由

la21 では ILS+PR は ILS-baseline とほぼ同等（2353 vs 2355）で加算効果は微小。
la36 でも ILS-baseline より下（1558 vs 1673）で、IQR が広く trial 間のばらつきが大きい。

ILS の探索は S₀ 近傍に留まりやすいため、PR の経路が短くなり中間解に改善の余地が生まれにくい。「経路の長さ ≒ 始点と S₀ の距離」が PR の効果を決める構造的原因。

### 5.2 Memetic の特性

**la21**: Memetic 系は ILS 系とほぼ同等の HV を達成。全 weight で改善成功率 100%。
**la36**: Memetic+repair が ILS 系に迫る中央値（1628）を安定した IQR（[1626, 1635]）で記録。ILS-baseline の IQR（[1548, 1684]）より分散が小さく、安定した探索をしている。

high_stab 領域では la36 で Memetic+repair が最大 HV（1400）を達成。GA のポピュレーションが持つ解の多様性が、PR・repair の引き戻し機構と組み合わさって高安定性方向へのアクセスを改善していると解釈できる。

### 5.3 la21 と la36 の差異

la21（小規模・15×10）では ILS 系・Memetic 系ともに高性能で大きな差はない（ILS+repair が最高）。
la36（大規模・15×15）では ILS-baseline が最高中央値を示しつつも IQR が広く、Memetic+repair が安定性と高い HV を両立している。問題規模が大きいほど Memetic の安定性優位が現れている可能性がある。

| 用語 | 意味 |
|---|---|
| weighted sum sweep | eff/stab の重みを 0.1 刻みで変えながら複数回 run し、解集合を統合する手法 |
| HV (Hypervolume) | Pareto 前線が参照点を覆う超体積。多目的最適化の主要指標 |
