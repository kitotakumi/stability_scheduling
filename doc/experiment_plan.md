### 優先度1: 安定性修復型摂動の設計

**現状**: 摂動は swap（N5ランダム）と insert（完全ランダム）の2種。insert は安定性の良い解を出しやすいことが実験で確認済みだが偶然に依存しており、insert の構造上の問題として `pop/insert` が i〜j 間の全 op を ±1 シフトさせるため安定性への影響が予測困難（cascade 問題）。direct swap なら2つの op の相対順序だけが変わり、安定性効果が精密に制御できる。

**設計方針**: insert にバイアスをかけるのではなく、安定性修復と多様化を**役割分離**した摂動オペレータを設計する。

**候補（優先順）**:

- **(P-1) Mini-PR kick（direct swap K ステップ）**: 初期解との不一致位置から K 個を選び、direct swap で初期解方向に修正する。PR のムーブ戦略を摂動として軽量利用。cascade なし、安定性効果が予測可能。K=1〜3 程度で「軽い修復キック」として機能。
  - 強み: 既存 `_count_diffs` + PR のロジックを流用でき実装が軽い
  - 弱み: 不一致位置の選択順序で結果が変わる（ランダム or greedy の設計判断あり）

- **(P-2) Displacement-targeted repair（最大偏差狙い撃ち）**: 各 op の rank deviation を計算し、deviation が最大の op を direct swap で初期位置に近づける。CSP の Min-Conflict heuristic（最も制約違反の大きい変数を優先修正）の発想。少ない操作で安定性を効率よく改善。
  - 強み: 安定性コストの高い箇所を狙い撃ちにするので費用対効果が最も高い
  - 弱み: deviation 最大の op が複数機械に分散する場合、1回の swap では修復しきれない

- **(P-3) Ruin-and-Recreate（破壊と再構築）**: VRP の大規模近傍探索由来（Schrimpf et al. 2000）。機械からランダムに K 個の op を除去し（ruin）、初期解の順序で再挿入する（recreate）。「破壊」で多様化、「再構築」で安定性修復を同時達成。insert の cascade 問題もない（一度抜いてから入れ直すので順序の帳尻が合う）。
  - 強み: 多様化と修復の両立、K で強度を自然に制御できる
  - 弱み: recreate の再挿入順序の設計に自由度があり、実験パラメータが増える

- **(P-4) Partial machine reset**: 1〜2台の機械をランダムに選び、その機械の順序を初期解に完全リセット。他の機械は現状維持。航空機運航回復の recovery operator の発想。
  - 強み: 実装が極めてシンプル（`machine_orders[m] = initial_machine_orders[m]`）
  - 弱み: リセット対象の機械選択が結果を大きく左右。全 op の位置が変わるため P-1/P-2 より粗い

**実験計画**: まず P-1（最もシンプル）を実装・評価し、安定性修復型摂動のメカニズム自体の有効性を確認。効果があれば P-2、P-3 と比較実験。P-4 はベースライン。

**注意点**: バイアスが強すぎると摂動の多様性が失われる（PRのgreedy化失敗と同じ轍）。狙いは「安定性方向に偏った出発点からLSを走らせると、LSが別の盆地に落ちて結果的に安定性も良い局所最適解に到達する」というメカニズム。修復型摂動は swap/insert を置き換えるのではなく、**組み合わせ**て使うことを前提とする。

### 優先度2: 摂動 strength の適応的制御

**現状**: `no_improve_count % 3 == 0` で +1、上限 `max_strength=5` のハードコード。

**改善案**: insert と swap で strength の影響度が異なる（insert は1回でも大きな変化）ため、手法別に制御を分離する。問題サイズに応じた上限調整も検討。

## 2. 確定済み判断

実験・検討を経てクローズした事項。今後は原則として再開しない。

### アルゴリズム設計

| 判断 | 結論 | 根拠 |
|---|---|---|
| `active_schedule` | `False`（semi-active）固定 | N5近傍の理論保証はsemi-active前提。activeではmachine_ordersと実処理順序が乖離する |
| `stagnation_threshold` | `None`（改善のみ受理）がデフォルト | 悪化受理はMS改善とSt悪化のトレードオフ。重み付きスコアでは大半の問題でデフォルトが優位（2026-04-14実験） |
| Taillardスクリーニング | 合成スコア下界フィルタ方式に確定 | `est_ms <= current_ms` では安定性重みありで実質無効化されていた（2026-04-14修正） |
| `strategy` (LS戦略) | `'best'`（最良改善）固定 | FI vs BI を4問題×2重み×10試行で比較したが有意差なし（2026-04-15実験・コードレビュー）。構造的理由: Taillardスクリーニングが全候補の安定性を先行計算するため BI/FI ループに入る前のコストが支配的。加えてN5近傍サイズが2〜6程度と小さく、評価回数の差が出ない |

### やらないこと

| 内容 | 理由 |
|---|---|
| Path Relinking のさらなる改良 | N5局所探索後にPRを適用してもLSが変更を打ち消す。構造的に困難（`path_relinking.md` 6.12）。ただし先行判断は**重み付きスカラーのみ**での評価に基づくため、Pareto / HV / 差分 EAF で再評価すると結論が変わる余地がある（`path_relinking.md` 6.13）。実験 1 完了後の余力で再評価枠を立てる可能性あり |
| SA的な温度パラメータ導入 | best/current分離 + accept_delta で十分。調整コストに見合わない |
| N7近傍やinsert近傍の局所探索への導入 | N5の理論的保証（閉路フリー・高速）が失われる。摂動レベルの改善を先に進める |
| VNS的な制御構造 | swap と insert の2種類しかなく恩恵が小さい。insert バイアスの結果次第で再検討 |
| first-improvement LS | N5+Taillard構成では FI に速度優位がない（上の `strategy` 行参照） |
